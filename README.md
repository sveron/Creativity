# Creative User Identification from Code Writing

This repository contains Jupyter notebooks for analyzing and identifying creative users based on their code-writing patterns.

## Dataset

The repository includes the dataset and its description, with two main files for the same set of users:

- **`TTCT_AUT_LOG.csv`**: Contains data related to TTCT files.
- **`kodetuTau-interactions_pre_post.xlsx`**: Includes pseudocode for various levels and outcomes.
